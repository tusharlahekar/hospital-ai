# Supra Hospital AI Assistant — Setup Guide

## What this is
A Flask web app that answers clinical/admin questions using ONLY Supra Hospital's
own knowledge base (15 protocols/decisions), with:
- **Safety overrides** — e.g. asking about patient "Rajan" always surfaces his
  NSAID drug alert first, no matter how the question is phrased.
- **Version enforcement** — sepsis questions always get the current v3 protocol
  (1-hour lactate), not outdated info.
- **Role-based confidentiality** — the FY2026 budget and expansion plan are only
  shown to "Admin"/"HOD" roles; a Doctor or Nurse asking gets it withheld.
- **Works with zero paid tools.** If you don't set up an LLM key, it runs in
  offline retrieval mode (deterministic, template-based answers built straight
  from the knowledge base — this alone is enough for the demo). If you add a
  **free** Groq API key, answers become natural-language and are generated by
  an LLM but still grounded strictly in the hospital context.

---

## Step 1 — Install Python dependencies (2 min)
Open the `hospital-ai` folder in VS Code, open a terminal (`` Ctrl+` ``), then:

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Mac/Linux

pip install -r requirements.txt
```

## Step 2 — (Optional but recommended) Get a free LLM key (3 min)
1. Go to https://console.groq.com/keys — sign up free, no credit card.
2. Create an API key.
3. Copy `.env.example` to `.env` and paste your key:
   ```
   GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxx
   GROQ_MODEL=llama-3.3-70b-versatile
   ```
If you skip this step entirely, the app still works — it just answers in
offline/template mode instead of natural language. **Don't burn time on this
if it's not working; the offline mode is a fully valid working prototype.**

## Step 3 — Run it (1 min)
```bash
python app.py
```
Open http://127.0.0.1:5000 in your browser.

## Step 4 — Demo it (test queries are pre-loaded as buttons in the UI)
Run each of these in your app, then run the *same* query in raw ChatGPT
(chatgpt.com, no context given) and compare side by side — this comparison
is your core deliverable:

1. "What pain medication should I give a post-TKR patient?"
   → Supra app: Paracetamol 650mg QDS, escalate to Tramadol, **avoid NSAIDs**
     (bleeding risk), cites Dr. Vikram's Jan 2025 decision.
   → ChatGPT: generic multimodal analgesia advice, will likely suggest NSAIDs
     as an option — which is actively wrong/dangerous for Supra's patients.

2. "Patient Rajan has knee pain, what should I prescribe?"
   → Supra app: leads with the CRITICAL cardiac stent / dual-antiplatelet
     NSAID alert before anything else.
   → ChatGPT: has never heard of Rajan — cannot warn you at all. This is the
     single clearest proof of why a hospital can't just use ChatGPT.

3. "When should I start DVT prophylaxis after surgery?"
   → Supra app: Enoxaparin 40mg SC, 12 hrs post-op, 14/28-day duration by
     procedure.
   → ChatGPT: generic timing ranges, no Supra-specific drug/dose/duration.

4. "What's our sepsis protocol?"
   → Supra app: v3, 1-hour lactate (explicitly flags that this was tightened
     from v2's 3 hours — an old habit could kill a patient).
   → ChatGPT: generic Surviving Sepsis Campaign guidance, no idea Supra
     tightened its own internal timing.

5. "Tell me about Mrs. Padma's medication management"
   → Supra app: knows her by name — fasting pattern, hypoglycemia history,
     the specific protocol adjustment made for her.
   → ChatGPT: has never heard of Mrs. Padma.

**Bonus** — ask "What's the ortho budget for FY2026?" as role=Doctor (refused)
vs role=Admin (answered). This demonstrates access control, which ChatGPT has
no concept of at all.

## Troubleshooting
- If port 5000 is taken, edit the last line of `app.py` to a different port.
- This app has **zero compiled dependencies** (just flask/requests/python-dotenv),
  so `pip install -r requirements.txt` should be quick and reliable on any
  machine — no C/C++ build tools needed.
- If the Groq call errors out mid-demo, the app automatically falls back to
  offline mode — the demo will not crash.
